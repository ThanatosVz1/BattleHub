# ⚔️ MCOC BattleHub — Unofficial Community & Units Progression Command

A dedicated, unofficial fan web platform designed for **Marvel Contest of Champions (MCOC)** summoners. Built with the authentic aesthetic inspired by [playcontestofchampions.com](https://playcontestofchampions.com/) — utilizing Contest Gold (`#ffcc00`), Signature Contest Red (`#e51937`), Deep Cosmic Void (`#000b14`), and angular chamfered game HUDs.

Built to track official event news, provide deep node and boss explanations, offer individual account tracking for **Units Progression (towards the 30,000 Banquet Vault)** modeled directly on `Units_Progression.xlsx`, compare progression with other summoners, rank on daily/weekly/monthly leaderboards, and engage in fair-play community strategy discussions.
